# Collage App

A simple Flask application that creates a collage from uploaded images with a style prompt.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the app:
   ```bash
   python app.py
   ```
3. Open your browser at `http://localhost:5000` to use the app.

You can include words like "pointillism" in the style prompt to apply a simple artistic filter to the final collage.
